# 19號舖子 IG 動畫輪播小工廠

每 10 分鐘跟網站後台拿「待製作」的工作 → 每張商品照片做成一支 3 秒多的小動畫（1080×1350）→ 放到 GitHub Pages（`/v/<編號>-<第幾張>.mp4`）。
19號小幫手巡邏時看到全部做好了，就把這幾支影片組成**同一則 IG 輪播貼文**發出去（文案附互動 CTA）。

- 模板：`src/Clip.jsx`（背景固定、商品框從躺平立起來變正方形、名稱和價格跳出來；第一支提示往右滑、最後一支放留言／LINE 下單）
- 設定：`config.json`（網站後台網址、影片保留天數）
- 手動跑一次：Actions → 做 IG 影片 → Run workflow
